# LLM Fine-Tuning

A structured, project-oriented learning repository covering the fundamentals and practical workflow of adapting pretrained language models to specialized tasks.

## Overview

This repository is a working knowledge base for **LLM fine-tuning** — from understanding pretrained models and datasets to supervised fine-tuning, parameter-efficient methods, evaluation, and deployment considerations.

The goal is to turn theoretical concepts into practical, reproducible LLM engineering workflows.

## Topics Covered

- Pretrained language models
- Tokenization and model inputs
- Instruction tuning
- Supervised fine-tuning (SFT)
- Dataset preparation and formatting
- Training configuration
- Evaluation and validation
- Parameter-efficient fine-tuning (PEFT)
- LoRA and related techniques
- Model checkpoints and artifacts
- Inference and deployment considerations
- Fine-tuning vs. RAG vs. prompting

## Engineering Focus

**Data → Formatting → Tokenization → Training → Evaluation → Inference**

This repository also documents when fine-tuning is appropriate and when alternatives such as **prompt engineering or Retrieval-Augmented Generation (RAG)** are more suitable.
