# Model Files

This directory contains the smaller supporting files for **Fine-Tuned Model 1 — DeBERTa-v3 Email Threat Classifier**.

## Files

- `config.json` — model architecture and sequence-classification configuration
- `deployment_info.json` — deployment and evaluation metadata
- `forentisai_model.json` — project/model metadata
- `tokenizer_config.json` — tokenizer configuration

## Complete Model Package

The complete model package, including the large model weights and tokenizer assets, is hosted on Hugging Face:

https://huggingface.co/sudiptaroy07/forentisai-deberta-v3-email-threat-classifier

The large model artifact is intentionally not duplicated in this GitHub repository.

## Purpose

These supporting files make the GitHub repository useful for understanding the model configuration and project metadata while Hugging Face provides the complete downloadable model.
